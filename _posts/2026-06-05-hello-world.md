First post on the new setup. I moved off WordPress — this blog is now just
Markdown files in a GitHub repo, built with [Jekyll](https://jekyllrb.com).

To add a post:

1. Create a file `_posts/YYYY-MM-DD-title.md`
2. Add the front matter (the block at the top of this file)
3. Write Markdown
4. `git push`

GitHub builds and deploys it automatically. That's the whole workflow.
